# 17. Typography

Use a premium Devanagari font pairing.

Suggested:
- Headings: Noto Serif Devanagari / another elegant Devanagari display font
- Body: Noto Sans Devanagari
- English UI labels: Inter or similar clean sans-serif

Prioritize Hindi readability.

# 18. UI Components

Create a reusable design system:

### Buttons
- Primary: saffron filled + cream text
- Secondary: cream/transparent + gold border

### Cards
- Cream/white surface
- Thin gold border
- Small shadow
- Traditional icon

### Sections
- Cream base
- Alternating white/cream sections
- Saffron or dark-brown devotional banners

### Decorative elements
Use subtle:
- Mandala-inspired line art
- Temple arch shapes
- Om / trishul-inspired decorative motifs
- Gold ornamental dividers

Do not overcrowd the UI.
